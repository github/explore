A DeepSeek Harness (DSH) plugin is an extension that participates in the Harness plugin-based composition. Plugins can add tools, model providers, skills, user interfaces, transports, storage, policies, and integrations without changing the core runtime. Repositories use the `dsh-plugin` topic to identify extensions and compatible projects for the DeepSeek Harness ecosystem.
