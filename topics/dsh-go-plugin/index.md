DSH Go is an Android client for working with AI models. The dsh-go-plugin topic groups repositories that publish compatible declarative plugins for the client, including companion pets, themes, chat backgrounds, and local AI skills.

Plugins are distributed as .dshgo.json packages. A repository can expose a dsh-go-catalog.json catalogue to let people discover and install its plugins from the app. These mobile packages are distinct from desktop DeepSeek Harness plugins and do not execute desktop JavaScript or native modules.

The [community plugin hub](https://github.com/mionio233-collab/dsh-go-plugins) documents the package format and publication workflow. Developers can publish packages in their own repositories and use this topic to make them discoverable.
