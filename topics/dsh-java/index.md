DeepSeek Harness Java (dsh-java) is a modular agent runtime for Java 17 and Spring Boot 3.3, organized around DDD ports and plugin mechanisms. Model adapters, tool registries, session event logs, and the ReAct agent loop can be replaced or extended. Java SPI, Node Bridge, and MCP plugins mount external capabilities; plugin stop or unload automatically revokes tool, system prompt, and hook registrations.
