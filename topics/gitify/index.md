Gitify is an open source desktop application that brings notifications from Git hosting platforms to the menu bar or system tray on macOS, Windows, and Linux.

It supports GitHub Cloud, GitHub Enterprise Server, GitLab, Gitea, Forgejo, Codeberg, and Bitbucket Cloud, so developers can review, filter, and mark notifications as read from multiple accounts in one place.

Gitify is built with Electron and React and is maintained by Adam Setch and Afonso Jorge Ramos.
